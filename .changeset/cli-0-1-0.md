First release of the `krino` command line. It reads krino's JSONL traces with DuckDB and helps you set up. Experimental: options and output may change in any release.

**`krino report [--project] [--trace-dir] [--since 7d] [--tokens-per-tool] [--json]`**

- Shows, per decision kind and mode: calls, agreement per host (labeled with that host's metric), the estimated cost saved if enforced (cache read and write tokens included), and added latency.
- Shows cache health as the cache read share for all runs and for multi-step runs only. A one-step run cannot read from the cache, so the "next step" cache rule uses the multi-step share.
- Shows the cut-off count and one "next step" line.
- Lines with a bad `traceSchemaVersion`, invalid JSON or a wrong shape are skipped and counted.
- `--json` prints a stable, documented shape (`reportSchemaVersion: 1`, with `cacheHealth.multiStepRuns`).
- The banner and colors respect `NO_COLOR` and non-terminal output.

**`krino init [--trace-dir] [--force]`**

- Finds `ai` or `@anthropic-ai/claude-agent-sdk` in `package.json`, writes `krino.config.json` (project name, every decision mode `shadow`, and `traceDirectory` only when `--trace-dir` is given), and prints the wrapper snippet for that host.
- Never edits source files. Will not overwrite an existing config without `--force`.
- In v0.1 only the CLI reads `krino.config.json`.

**`krino doctor [--project] [--trace-dir]`**

- Checks Node ≥ 22, the host SDK versions (`ai` `>=7.0.111 <8`; `@anthropic-ai/claude-agent-sdk` tested with 0.3.286), whether `AI_GATEWAY_API_KEY` is present (it never prints the value), fake-provider decisions, whether the trace folder is writable, and whether recent traces parse.
- Checks the cut-off rate (warns above 5%) and cache health (warns below a 50% cache read share on multi-step runs, using the same token sources as `krino report`).
- Warns when a relative `traceDirectory` in the config resolves to a different folder for the runtime than for the CLI.
- Every warn or fail comes with a fix line. A check with nothing to check yet shows a dimmed SKIP, which never counts as a pass. Exits 1 on any fail, otherwise 0.

**Install**

- Depends on `@krinolabs/krino` with a caret range, so it shares the copy your project already installs.
- Reads traces from the folder the runtime writes to (`resolveTraceDirectory` from `@krinolabs/krino`).
